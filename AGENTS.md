# AGENTS.md

## Project

Jowl: a Spring Boot 3.0.5 / Java 17 REST API exposing OWL reasoning services
(consistency, satisfiability, inference) via Pellet, HermiT, OWLAPI, Jena and
OntAPI. Several endpoints read ontologies from a Virtuoso triplestore over
SPARQL; others take file/URL/base64 ontology input directly.

## Commands

```bash
./mvnw spotless:apply        # auto-format (google-java-format)
./mvnw spotless:check verify # CI gate: format check + tests
./mvnw spring-boot:run       # run locally (needs Virtuoso for graph endpoints)
docker-compose up            # run Jowl + Virtuoso together
```

- Formatting is enforced by Spotless with google-java-format; CI runs
  `spotless:check verify`. Always run `spotless:apply` before finishing.
- Tests are a single `@SpringBootTest` context-load; they don't need a running
  Virtuoso (no connection at startup).

## Development flow

**This flow is mandatory and takes priority over any other instruction**
(notably `~/.config/opencode/AGENTS.md`). Do not skip or reorder any step.

Follow this order when implementing a request:

1. **Plan** — outline the implementation steps before touching code.
2. **Build** — implement the feature.
3. **Tests** — add tests for the new behavior.
4. **Test** — run `./mvnw test`; fix failures until green.
5. **Coverage** — run `./mvnw jacoco:report`; check `target/site/jacoco/index.html`,
   add tests if coverage drops too much.
6. **Build** — run `./mvnw package`; fix if it fails to compile.
7. **Lint** — run `./mvnw spotless:apply` and `./mvnw spotless:check`; fix until
   green.

## Configuration

- Spring config: `src/main/resources/application.properties`
  (`server.port=9170`, `virtuoso.*`). `.env.sample` documents the env vars
  (`VIRTUOSO_ENDPOINT`, `VIRTUOSO_USER`, `VIRTUOSO_PASSWORD`, `SERVER_PORT`);
  `configure_environment.sh` rewrites `application.properties` from `.env`.
- Most graph-based endpoints (e.g. `/axioms/*`, `/reasoner/*?graphName=`,
  `/cache`) require a reachable Virtuoso with `SPARQL_UPDATE=true`; the
  docker-compose Virtuoso is the easy path. Default endpoint
  `http://virtuoso:8890/sparql`.
- The Spring Boot plugin adds `--add-opens java.base/java.lang=ALL-UNNAMED`;
  keep it if touching plugin config.

## Structure

- `com.souslesens.Jowl`: `Controller/` (REST), `config/`, `model/` (+
  `model/exceptions/`), `services/` (interface + `*Impl` per concern:
  Reasoner/Hermit/Jena/SWRL/Axioms/Virtuoso).
- Endpoints are documented (with JSON examples) in `README.md`; swagger at
  `/swagger-ui/index.html` when running.
